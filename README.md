# Behavioral Task Analysis
N-Back and Stroop Tests

This repository contains Python scripts for preprocessing and analyzing behavioral data from classic cognitive paradigms. The scripts are designed to process raw, nested output files generated by PsychoPy and compute standard psychometric performance metrics. The specific project I worked on consisted of 2 sessions, such experimental choices should be adapted in the script accordingly.

## Included Scripts

- **`nback_analysis.py`**
    
    - **Preprocessing:** Automatically scans nested PsychoPy output directories to locate and extract the correct T1 and T2 session files for each subject.
        
    - **Reaction Time:** Calculates the mean reaction time for both 0-back and 2-back conditions.
        
    - **Accuracy (d'):** Computes d-prime sensitivity from hits and false alarms. Applies a +0.5 Hautus correction to prevent infinite z-scores when hit or false alarm rates are exactly 0% or 100%.
        
- **`stroop_analysis.py`**
    
    - **Stroop Effect:** Calculates the classical Stroop effect by subtracting the median reaction time of congruent trials from incongruent trials.
        
    - **Data Cleaning:** Automatically filters out incorrect trials before reaction time computation and outputs an overall Stroop accuracy percentage for each session.
